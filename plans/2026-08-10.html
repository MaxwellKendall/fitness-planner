A one-off mile is run noticeably faster than 10K pace — going by your sub-60:00 10K, 8:00–8:30 for a genuine all-out mile is a realistic, exciting target, not a moonshot. Warm up properly, run the first quarter controlled (it's easy to blow up going out too hot), and empty the tank in the back half. No pressure if the town/heat/sand isn't cooperating that morning — it's just for fun, re-run it Friday instead if you want another crack at it.

Bonus, only if you're curious: that same 10K fitness maps to roughly a 28:00–29:00 5K (~9:00/mi pace) — worth testing on the long Thursday run if you feel good and want a mid-run hard segment instead of a full easy cruise.

One caution: if daily running isn't normally in the mix, new terrain (sand, unfamiliar streets) plus a hard mile effort is exactly the kind of novel load that causes shin/calf soreness. If Tuesday leaves you sore, dial back Thursday's distance rather than pushing through.
